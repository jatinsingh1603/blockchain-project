    Attack lab

    Each attack runs against the APK you loaded and shows what the gate decides.

    • Build server hackedB3 is compromised and votes for a backdoored build. The file carries the real certificate.
    • Signing key stolenThe attacker injects code and signs with the real key. No builder voted for it.
    • Repackaged appInjected code, re-signed with the attacker's own key (certificate swap is simulated).
    • DowngradeThe developer raises the minimum version above this one.
    • Revoked releaseThe developer revokes this version, then a user tries to install it. Run this last.
    • Outsider tries to voteAn account that is not a builder sends a vote.

    Prototype for the paper "When a Valid Signature Lies: Blockchain Quorum Verification Against Signed Malware in Android Apps", Jatin Kumar Singh, The NorthCap University. The real ReleaseRegistry contract runs on a private Ethereum chain inside this page (ethereumjs). No wallet and no real coins are used. Demo APK from the androguard test suite (Apache 2.0).
